## 📖 Overview

The Online Passport Appointment System is a software engineering project focused on digitizing and organizing the passport appointment process.

Traditional appointment workflows can involve manual coordination, repetitive data entry, and difficulty tracking application progress. This project proposes a centralized system where applicants can manage their passport-related requests and appointments, while authorized personnel can review applications and manage appointment records.

The repository also contains the Software Requirements Specification (SRS) and system design documentation.

## 🎯 Objectives

- Simplify the passport appointment-booking process.
- Reduce manual paperwork and repetitive administrative tasks.
- Maintain organized applicant and appointment records.
- Improve transparency in application-status tracking.
- Provide a structured workflow for application review and processing.
- Define clear functional requirements and system interactions.

## 🔄 Application Workflow

The proposed workflow is:

1. The applicant accesses the system.
2. The applicant registers or logs in.
3. The applicant provides the required passport application information.
4. The applicant submits the application.
5. The applicant selects an available appointment, where supported.
6. The system records the application and appointment information.
7. Authorized personnel review the submitted information.
8. The application status is updated.
9. The applicant checks the latest available status.
